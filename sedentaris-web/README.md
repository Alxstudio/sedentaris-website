# Sedentaris.Cat — Official Club Website

Official website for Club d'Atletisme Sedentaris.Cat, 
an athletics club founded in Castelldefels in 2008.
Freelance project built as part of my portfolio.

## Stack
Next.js (App Router) · TypeScript · Tailwind CSS v4 · Supabase (pending)

## Status
Frontend completed. Backend integration (Supabase), 
i18n (Català + Spanish) and admin backoffice in progress.

- Home · El Club · Atletes · Blog · Tarifes · Roba · Contacte
